# 小数のたし算・ひき算

4年生の小数のたし算・ひき算を、位を意識しながら練習する算数教材です。

公開ページ： https://tt-sensei.github.io/shosu4nen/

## 学習の流れ

1. 計算する前に、答えの見当（だいたいの大きさ）を選ぶ。
2. 下の数を動かし、小数点を縦にそろえる。
3. 位ごとに計算し、くり上がり・くり下がりを確かめる。筆算の上には位の名前と小数点のガイドをいつも表示する。
4. 小数点をそろえて答えを書く。
5. 最後に筆算を隠し、式だけを見て自分で答えを入力する。ここで筆算の答えを再現するだけでなく、計算全体を確かめる。

## 問題の種類

- 小数第1位どうしの計算
- 小数第2位どうしの計算
- 小数第1位と第2位が混ざった計算
- 整数と小数のたし算・ひき算
- 整数から小数をひく、0をまたぐくり下がり

問題は練習のたびに自動生成されます。たし算・ひき算は、上の6つの型が10問の中に必ず1問ずつ入るように出題を管理します（かけ算は小数第1位・第2位、わり算は わられる数のけた数を交互に出します）。間違えた問題は「とっくん」に記録され、正解すると記録から外れます。練習結果では、途中で間違えて直した問題と、最初からノーミスで解けた問題を区別して表示します。

## 学習支援

- 位の名前を示すガイドで、小数点を基準に位をそろえる。ガイドは位そろえのときだけでなく、位ごとの計算のあいだも表示し続ける。
- 計算の前に答えの見当を選ぶステップで、答えの大きさを捉える力を育てる。見当違いは間違いとして記録しない。
- ナビキャラは種類ごとに担当を固定する（たし算＝りく、ひき算＝そら、かけ算＝つき、わり算＝かい）。
- 最初は考え方のヒントを示し、再度間違えたときに計算過程を確認する。
- くり下がりが続く場合も、0の位を含めて順に考えられるようにする。
- 最後の自力チャレンジで、筆算の手順を式だけの計算に結び付ける。
- とっくんでは、前回つまずいた段階（位合わせ・位ごとの計算・小数点の位置など）を示し、意識するポイントを明確にする。
- 問題ごとに誤答した学習段階を保存し、複数の段階でつまずいた場合も記録する。
- 問題が変わるたびに、位合わせのヒント回数をリセットする。

## 技術・利用

- HTML / CSS / JavaScriptで動作する静的な教材です。
- 学習記録は利用端末のブラウザー内に保存します。
- 学習に外部APIやサーバー側データベースは使用しません。
